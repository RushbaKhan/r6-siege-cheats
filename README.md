# R6 Siege Cheats

Production website for [r6siegecheats.com](https://r6siegecheats.com) — Rainbow Six Siege cheats with operator ESP, aimbot, wallhack, and gadget ESP.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output is in `dist/` for Cloudflare Pages deployment.

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- React Router
